# Course Images

Add one image per course using its exact course slug as the filename. Supported extensions are `.webp`, `.png`, `.jpg`, `.jpeg`, and `.avif`:

```text
<course-slug>.<extension>
```

For example, the Python website development course uses:

```text
website-development-python.png
```

Matching images are picked up automatically by the shared course data and used on course cards, detail pages, and social previews. Until a matching image is added, the course keeps its current image.
